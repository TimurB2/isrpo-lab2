# Общее описание решения
---
**Назначение**
---
Проект придназначен для вычисления площадей и периметров различных простых геометрических фигур(окружности, прямоугольника, треугольника, квадрата).
--- 
**Реализация**
---
Проект реализован на языке python и с использованием библотеки math.

Для каждой фигуры функции с вычислением их площади и периметра лежат в отдельном файле.
---
**Входные и выходные данные**
---
На вход программа поллучает числовые значения параметров фигуры необходимых для вычисленния периметра или площади.

На выход программа возвращает числовое значение периметра или площади фигуры
---
# описание функций с прмерами вызова
---
**triangle.py** - функции для треугольника
---
**area(a,h)** - Возвращает площадь треугольника с задаными стороной и длинной высоты опущенной на нее
- Параметры:

    a(float): сторона

    h(float): высота опущенная на сторону

- Возвращаемое значение(int or float): площадь треугольника со стороной a и высотой h
- Пример вызова: area(2,3) -> 3

**perimeter(a,b,c)** - Возвращает периметр треугольника с задаными сторонами
- Параметры:

    a(float): сторона

    b(float): сторона

    c(float): сторона

- Возвращаемое значение(float): периметр треугольника со сторонами a,b и c
- Пример вызова: perimeter(1,2,3) -> 6
---
**square.py** - функции для квадрата
---

**area(a)** - Возвращает площадь квадрата с заданой стороной

- Параметр a(float): сторона квадрата
- Возвращаемое значение(float): площадь квадрата со стороной a
- Пример вызова: area(2) -> 4

**perimeter(a)** - Возвращает периметр квадрата с заданой стороной

- Параметр a(float): сторона квадрата 
- Возвращаемое значение(float): периметр квадрата со стороной a
- Пример вызова: perimeter(2) -> 8
---
**rectangle.py** - функции для прямоугольника
---

**area(a,b)** - Возвращает площадь прямоугольника с задаными длиной и шириной

- Параметры: 

    a(float): ширина

    b(float): длина

- Возвращаемое значение(float): площадь прямоугольника с длиной a и шириной b
- Пример вызова: area(2,3) -> 6

**perimeter(a,b)** - Возвращает периметр прямоугольника с задаными длиной и шириной

- Параметры: 
    a(float): ширина
    b(float): длина
- Возвращаемое значение(float): периметр прямоугольника с длиной a и шириной b
- Пример вызова: perimeter(5,3) -> 16
---
**circle.py** - функции для круга
---

**area(r)** - Возвращает площадь окружности с заданым радиусом r

- Параметр: r(float): радиус окружности
- Возвращаемое значение(float): площадь окружности радиуса r
- Пример вызова: area(4) -> 12.5663706

**perimeter(r)** - Возвращает длину окружности с заданым радиусом r

- Параметр: r(float): радиус окружности
- Возвращаемое значение(float): длина окружности радиуса r
- Пример вызова: perimeter(3)->18.8495559
